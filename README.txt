ATTENDENCE.IN — STUDENT ATTENDANCE TRACKER

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in Chrome, Edge, Firefox, etc.
4. Add your subjects under "My subjects".
5. Go to "Daily attendance", choose a date, select the subjects you have, and click "Add selected classes".
6. Each newly added class starts as Absent. Mark Present or Absent for each subject. Your attendance percentage updates automatically.

FEATURES
- Dashboard with subject-wise and overall attendance.
- Add, rename and delete subjects.
- Date-based daily attendance entry.
- Prevents duplicate entries for the same subject on the same date.
- Edit attendance from the daily screen or history.
- Attendance history with subject filter.
- 75% attendance calculator.
- Light/dark appearance.
- Data saved in browser local storage.

IMPORTANT
This version saves data in the browser on the device where you use it. It does not sync between different devices or browsers. Do not clear browser site data if you want to keep your attendance records. For multi-device sync, a database and login system would be needed.
